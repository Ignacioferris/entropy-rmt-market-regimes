# Entropy and Random Matrix Theory for Market Regime Analysis

This repository contains the work developed for my undergraduate thesis.

The main objective is to study whether entropy-based measures and Random Matrix Theory can be used to identify different market regimes from financial data.

## Main idea

Financial markets can exhibit very different behaviours depending on the period being analysed.

The project explores whether changes in the structure and randomness of market data can help distinguish between regimes such as:

- Trending or relatively ordered periods
- Highly uncertain or chaotic periods
- Transitions between different market states

The approach will combine entropy measures with tools from Random Matrix Theory to study changes in the statistical structure of financial markets.
